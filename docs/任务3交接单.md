## 2. 第 1 步：接入任务1 的数据

```bash
python run_backtest.py --csv "任务1的数据文件路径.csv" --name baseline_csv
```

**字段要求**（与任务1 约定的长表格式）：

```
trade_date, code, name, open, high, low, close, volume
```

- 多一列 `return` 没关系，会自动忽略；
- `code` 必须是 6 位字符串（`000858` 不能变成 `858`）；
- 日期格式 `2018-01-02` 或 `20180102` 都能识别。

跑完后对比两份指标：

- `output/baseline_csv/metrics.md`（任务1 数据）
- `output/baseline/metrics.md`（akshare 数据）

数字接近（差异 < 1~2 个百分点）说明口径一致；差太多就查：复权方式（应为前复权）、日期范围、是否缺了停牌日。

**口径必须锁死**：样本内 2018-01-02 ~ 2021-12-31，样本外 2022-01-01 ~ 2026-11-20（数据由任务1 提供，已与 akshare 直连结果核对一致）。任何人不要为了结果好看改切分点。

## 3. 第 2 步：参数迭代（任务3 的核心）

### 3.1 均线策略：证明「参数敏感」

```bash
python scripts/run_grid.py --strategy ma_timing ^
  --grid fast=10,20,30 --grid slow=60,90,120 --grid signal_freq=daily,weekly,monthly
```

预期看到：**样本内最优参数和样本外最优参数对不上**，且相邻参数结果跳变（例如 20/60 与 30/90 一个赚一个亏）。
这就是「参数是在拟合噪声」的证据，写进报告。

### 3.2 风险平价：证明「参数稳健」

```bash
python scripts/run_grid.py --strategy risk_parity --grid lookback=20,40,60,90,120
```

预期看到：不同窗口的结果高度接近（累计 107%~112%、夏普 0.42~0.43），说明这个策略不靠调参。

### 3.3 看什么

1. **样本内最优 vs 样本外最优是否一致**——不一致就是过拟合；
2. **参数邻域是否平滑**——好策略在相邻参数上表现接近；
3. **换手率和成本**——收益是不是被交易磨掉的。

结果文件：`output/grid_<策略>/grid.csv`、`grid.md`。

## 4. 第 3 步：四项指标 + 样本内外 + 超额

每次运行都会自动生成 `output/<实验名>/metrics.md`，里面按**全样本 / 样本内 / 样本外**三列给出：

- 四项必备：累计收益率、年化收益率、最大回撤、夏普比率；
- 补充：年化波动、卡玛、索提诺、跟踪误差、信息比率、Beta/Alpha、换手率。

### 超额必须做两套基准

```bash
# 基准一：沪深300（市场基准，答辩最直观）
python run_backtest.py --strategy risk_parity --name baseline

# 基准二：同池等权买入持有（剥离选股，只看配置层）
python run_backtest.py --strategy risk_parity --benchmark buyhold --name benchmark_bh
```

结论要能回答：**超额里多少来自「选了三只白马股」，多少来自「配置/择时」**。

参考数字（2018-01-02 ~ 2026-11-20）：

| 期间 | 风险平价 | 等权持有 | 沪深300 |
|---|---|---|---|
| 全样本 | 106.77% | 91.78% | −3.25% |
| 样本内 2018-2021 | 142.12% | 169.72% | 20.87% |
| 样本外 2022-2026.11 | −14.48% | −28.94% | −19.59% |

要点：样本外是熊市（2022、2026 两轮下跌），三个口径全为负，但风险平价分别跑赢等权持有 14.5pp、跑赢沪深300 5.1pp——**如实写，别换基准掩盖**。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: akshare` | 没激活环境 | `conda activate quant` |
| `RemoteDisconnected` | 东财接口限流 | 已自动切新浪源；仍失败加 `--offline` 用缓存 |
| `--csv` 报「CSV 中缺少标的」 | 代码列丢了前导零 | 用 `dtype={'code': str}` 读入，`zfill(6)` 补零 |
| 图和基线不一样 | 换了区间/数据源 | 检查 `run_meta.json` 里的 config |
| 提交时提示 `data/raw` 太大 | 手动 `git add -f` 了 | `git rm --cached` 后重新提交 |
