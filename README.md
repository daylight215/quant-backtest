# quant-backtest —— A 股多标的量化回测系统

课程作业「周二下午量化交易」小组项目。本仓库实现了一个**可真实运行**的日频回测系统：
从 akshare 抓取 A 股日线 → 清洗对齐 → 策略生成目标权重 → 引擎按 A 股交易规则撮合 →
输出净值曲线、回撤图与绩效指标表。全程无未来函数，交易成本按真实费率建模。

> 本仓库代码由小组成员在 AI 编程助手（DeepSeek Harness）辅助下编写，策略逻辑、回测规则与
> 每个模块的设计取舍均由小组成员理解并可在答辩中解释。AI 辅助情况见文末「AI 使用说明」。

## 1. 系统架构

```
                    ┌──────────────────────────────┐
                    │        run_backtest.py       │  命令行入口：取数→回测→指标→出图
                    └──────────────┬───────────────┘
                                   │
   ┌───────────────┐   ┌───────────┴───────────┐   ┌──────────────────┐
   │  data/ 数据层  │──▶│ strategy/ 策略信号层   │──▶│ engine/ 回测引擎层 │
   │  抓取/缓存/清洗 │   │ 行情 → 目标权重        │   │ 撮合/费用/净值/指标 │
   └───────────────┘   └───────────────────────┘   └────────┬─────────┘
                                                            │
                                                   ┌────────▼─────────┐
                                                   │  viz/ 结果输出层  │
                                                   │ 净值图/回撤/热力图 │
                                                   └──────────────────┘
```

四层严格解耦：策略只看得见行情、看不见账户；引擎只负责按权重下单、不猜策略意图。
因此新增一个策略只需要实现 `generate_weights()`，不需要改动引擎任何一行代码。

## 2. 快速开始

```bash
# 1) 创建环境（已有 quant 环境可跳过）
conda create -n quant python=3.10 -y
conda activate quant
pip install -r requirements.txt

# 2) 跑默认策略（首次会联网抓数据并缓存到 data/raw/）
python run_backtest.py

# 3) 结果在 output/risk_parity_20180101_20251231/
```

常用命令：

```bash
python run_backtest.py --strategy risk_parity                 # 逆波动率风险平价（默认）
python run_backtest.py --strategy ma_timing --param signal_freq=monthly \
                       --param fast=20 --param slow=60        # 双均线择时
python run_backtest.py --strategy momentum --param lookback=60 --param top_k=1
python run_backtest.py --strategy buy_hold                    # 等权买入持有（对照）
python run_backtest.py --benchmark buyhold                    # 换成"等权买入持有"基准
python run_backtest.py --offline                              # 断网跑（用本地缓存）
python run_backtest.py --list-strategies                      # 查看可用策略
python scripts/run_grid.py --strategy ma_timing \
       --grid fast=10,20,30 --grid slow=60,90,120 --grid signal_freq=daily,weekly
python -m unittest discover -s tests -v                       # 单元测试
```

用任务1同学提供的数据文件（长表 `trade_date, code, name, open, high, low, close, volume`）：

```bash
python run_backtest.py --strategy risk_parity --csv D:\path\to\data.csv
```

## 3. 策略

### 3.1 默认策略：逆波动率风险平价（`risk_parity`）

- **信号**：过去 60 个交易日收益率的波动率 σ_i，权重 `w_i ∝ 1/σ_i`；
- **调仓**：每月最后一个交易日再平衡，其余时间持有不动；
- **依据**：低波动异象（Ang et al., 2006）——高波动股票的风险调整后收益反而更低；
  风险预算——避免组合波动被单只高波动股主导，让分散化真正生效；
- **实测**：年化换手仅 0.3 倍，交易成本侵蚀 0.03%/年，参数（20~120 日窗口）高度稳定。

### 3.2 对照策略：双均线趋势择时（`ma_timing`）

短均线在长均线之上、且收盘价在长均线之上时持有，否则空仓；等权分配。
支持日/周/月频信号确认（`signal_freq`）。它的作用是与默认策略对照，回答
"择时到底有没有用"——结论见第 6 节。

### 3.3 其他

- `momentum`：横截面动量（过去 N 日涨幅）+ 大盘 200 日均线风控，周/月调仓；
- `buy_hold`：三只股票等权买入持有，作为"什么都不做"的对照组。

## 4. 回测规则（答辩必问）

| 项目 | 处理方式 | 理由 |
|---|---|---|
| 成交时点 | T 日收盘出信号，**T+1 开盘**成交 | A 股 T+1，且杜绝"用当日收盘价成交"的未来函数 |
| 成交价 | 开盘价 × (1 ± 滑点) | 开盘价可交易，滑点 5bp 覆盖冲击成本 |
| 整手 | 买入按 100 股向下取整；清仓允许零股 | A 股一手 100 股 |
| 佣金 | 万 2.5，单笔最低 5 元，双边 | 券商常见费率 |
| 印花税 | 卖出单边：2023-08-28 前 0.1%，之后 0.05% | 2023 年 8 月印花税减半的真实政策 |
| 停牌 | 开盘价缺失不撮合，持仓按最近收盘价估值 | 停牌无法成交 |
| 现金 | 不允许透支，买入按手数递减直到买得起 | 无杠杆 |
| 分红送转 | 用**前复权**价格 | 复权价已包含分红再投资的影响 |

**防止未来函数的三道保险**：① 策略接口只给到当日收盘为止的数据；② 引擎统一 `shift(1)`
后才执行；③ 单元测试 `test_no_lookahead_t_plus_1` 断言"第 3 日信号必须第 4 日成交"。

## 5. 指标定义

| 指标 | 定义 |
|---|---|
| 累计收益率 | NAV_end / NAV_start − 1 |
| 年化收益率 | (1 + 累计)^(252 / 交易日数) − 1 |
| 最大回撤 | min(NAV / cummax(NAV) − 1)，并记录峰/谷/收复日 |
| 夏普比率 | (日超额收益均值 / 标准差) × √252，无风险利率 2% |
| 年化波动 | 日收益标准差 × √252 |
| 卡玛比率 | 年化收益 / \|最大回撤\| |
| 超额收益 | 策略收益 − 基准收益（累计与年化分别报） |
| 跟踪误差 / 信息比率 | 主动收益的标准差 / 均值÷标准差 |
| Beta / Alpha | 策略日收益对基准日收益做 CAPM 回归 |
| 年化换手率 | (买入额 + 卖出额) / 2 / 平均资产 / 年数 |

## 6. 回测结果（2018-01-02 ~ 2026-11-20，样本内 2018-2021 / 样本外 2022-2026）

基准：沪深300（`000300`）。初始资金 100 万元，三只标的：贵州茅台、招商银行、五粮液。

| 指标 | 风险平价（默认） | 双均线择时（周频） | 等权买入持有 | 沪深300 |
|---|---|---|---|---|
| 累计收益率 | **106.77%** | 51.99% | 87.81% | −3.25% |
| 年化收益率 | **8.87%** | 5.02% | 7.65% | −0.39% |
| 最大回撤 | −48.47% | −46.44% | −52.48% | **−45.60%** |
| 夏普比率 | **0.384** | 0.243 | 0.337 | −0.027 |
| 年化换手 | 0.3× | 6.8× | 0× | — |

分样本看，结论会更清楚（把基准换成"同一批股票的等权买入持有"，剥离选股影响）：

| 期间 | 风险平价 | 等权买入持有 | 沪深300 |
|---|---|---|---|
| 样本内 2018-2021 | 142.12% | **169.72%** | 20.87% |
| 样本外 2022-2026.11 | **−14.48%** | −28.94% | −19.59% |

**怎么解释这组结果（报告"超额收益来源"就写这四条）：**

1. 三只白马股 2018-2026 整体大幅跑赢沪深300，所以相对指数的超额（110pp）主要来自**股票池**，
   不是策略本身——这一点必须诚实说明，否则答辩会被问穿。
2. 样本内风险平价跑输等权持有 27.6pp：2019-2020 是白酒等高波动股的主升浪，逆波动率加权
   天然低配它们。这是低波动策略的**风格代价**，不是 bug。
3. 样本外风险平价跑赢等权持有 14.5pp、跑赢沪深300 5.1pp：2022 和 2026 两轮下跌里，
   低配高波动股、保留现金的组合更抗跌。同一套规则、零参数调整，说明配置层有真实的风险分散价值。
4. 全样本最大回撤 −48.47% 与沪深300（−45.60%）接近，但同期收益是 106.77% vs −3.25%——
   **承担同样的回撤，换来了完全不同的收益**，这是策略的核心卖点。

双均线择时把最大回撤压到 −46.44%，但收益只剩 51.99%、换手 6.8 倍，且参数稍变（30/90 日）
样本内结果就从 +52% 掉到负值——**不稳健**，因此没有选为默认策略。完整的参数网格见
`scripts/run_grid.py` 的输出。

## 7. 数据说明

- 主源：`akshare`（东方财富 `stock_zh_a_hist`，前复权）；
- 备源：新浪 `stock_zh_a_daily`（东财接口在部分网络环境下会断连，自动降级）；
- 基准：上证/深证指数接口 `stock_zh_index_daily`（沪深300 → `sh000300`）；
- 缓存：首次抓取后写入 `data/raw/`，之后离线可用（`--offline`）；
- **团队统一数据集**：`data/processed/全部清洗后数据.csv`（4 个标的、9836 行，含预热期，
  由 `scripts/build_dataset.py` 生成，可用 `scripts/check_data.py` 自检）；
- 体检：每次加载都会输出行数、起止日、重复日期、零成交日、涨跌幅异常提示；
- 数据只用于课程作业，未做任何未来数据修正。

## 8. 已知限制（写进报告的"反思"部分）

1. **股票池太小**：只有 3 只标的，且两只白酒高度相关，"分散"效果有限；
2. **整手约束**：茅台一手约 15 万元，占 100 万组合 15%，无法精确配到目标权重，
   会残留 3%~5% 现金拖累（引擎已用"按手数容忍带"避免为凑权重反复交易）；
3. **无融券/做空**：只能做多，下跌市只能空仓；
4. **日频**：未建模盘中冲击成本与集合竞价；
5. **分红**：用前复权价近似，未单独建模股息现金流与红利税；
6. **参数选择**：默认参数经过样本内观察，存在一定选择偏差，样本外表现才是真检验。
